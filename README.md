# Drone-OpenMV-red-object-tracking
This is a Raspberry PI Zero W linked to an OpenMV H7 plus camera via SPI and to a drone flight controller ( this was for my internship at GreenSight, so we used their WISP drone). It basically places a white box around the red object, tracking its size and position relative to the center of the camera, and will fly towards that object. If it doesn't see an object, it will simply hover. I used Mission planner to control the drone, and it has to be in guided mode in order to accept flight commands from the Pi. When me and my team ran this we would first put the drone in stabilize mode and fly it up to a moderate height oof about 3 meters, and then switch to guided mode and hold up a red sign and watch it fly towards the sign slowly. Its latency is kind of low because we were supposed to use a Zero 2 W, but they were out of stock and on a time crunch, but the SPI speed can be increased and it should work more efficiently that way.
